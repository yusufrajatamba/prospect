Koneksi Database Google Spreadsheet

Jadikan Google Spreadsheet pribadi Anda sebagai database cloud real-time 2 arah untuk Vercel & Web.

Target Google Spreadsheet: Buka Google Sheets
https://docs.google.com/spreadsheets/d/1ykj3cCMPYfhUI0n7H0cnY2TzdfXrEo4hG5HHp2-bejA/edit

URL ini didapatkan dari menu Extensions > Apps Script > Deploy > New Deployment > Web App di spreadsheet Anda.

Cara Deploy Apps Script ke Spreadsheet Anda (Hanya 3 Langkah):
  1. Buka link spreadsheet Anda di atas, pilih menu Extensions > Apps Script.
  2. Salin seluruh kode dari file google_apps_script/Code.gs ke editor Apps Script, lalu klik icon Simpan.
  3. Pilih fungsi setupAgentSheets di dropdown toolbar dan klik Run (1 kali untuk membuat struktur tabel).
  4. Klik tombol biru Deploy > New deployment, pilih jenis Web app:
    • Execute as: Me
    • Who has access: Anyone (Wajib agar Web & Vercel bisa akses)
  5. Salin Web App URL yang berakhiran /exec, tempelkan di kotak isian di atas, lalu klik Simpan & Aktifkan.
